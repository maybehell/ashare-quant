# Architecture Decision Records

ADRs preserve durable architectural decisions and their reasoning.

## Lifecycle

- `proposed`: under review, not authoritative.
- `accepted`: current decision.
- `superseded`: replaced by a later ADR; retained for history.
- `rejected`: considered but not adopted.

## Naming

Use `NNNN-short-kebab-title.md`. Numbers are monotonic and never reused.

## Required sections

- Status
- Date
- Context
- Decision
- Consequences
- Alternatives considered
- Supersedes / Superseded by, when applicable

Do not edit an accepted ADR to reverse its decision. Create a new ADR and mark
the earlier record superseded.
